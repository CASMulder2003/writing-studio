# Workspace design

The interface takes a manuscript-first approach with connected planning tools.
Neutral paper surfaces, muted green controls, and serif headings keep the writing
area visually calm. Manuscript text uses a compact 16 px serif style and generous
line spacing.

The left sidebar contains the manuscript order and the four main views: Manuscript,
Outline, Characters, and Notebook. The optional right panel shows chapter summaries,
attached notes, character information, and saved versions. On smaller screens it
opens as an overlay. Focus mode hides both sidebars and the project header.

The Outline gives each chapter a summary, status, word count, and estimated page
count. It is the main place to plan and rearrange the book. A smaller add-chapter
control remains available while writing.

Project tabs are closable, and the library remains accessible through +. Closing all
tabs shows the library. Closed projects are still saved and can be reopened.

Counts describe the current work rather than setting a target. The interface avoids
daily-goal slogans, estimated reading times, and a separate scene hierarchy.

The notebook supports both project-wide and chapter-specific notes. Attached notes
are the same record wherever they are opened, so edits remain consistent. Drawings
and image captions help keep visual research beside the writing.

PDF export separates chapter selection from the complete project backup. The writer
can export a partial draft in book form while retaining the full editable project.
